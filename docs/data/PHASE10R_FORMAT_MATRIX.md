# Phase 10R format and validation matrix

The normalized record contract is [`phase10r_normalized_record/v1`](../../configs/phase10r/normalization.yaml). Adapters preserve source bytes and source labels first; a record is not trainable until it has a canonical position, legal replay result, score semantics, provenance hash, and an approved rights decision.

| Source format | Observed encoding/layout | Adapter | Preserved fields | Legality / round-trip gate | Current sample result |
| --- | --- | --- | --- | --- | --- |
| CSA | WCSC sample is CP932; source uses `V2.2`; AobaZero uses the existing audited CSA path. | `parse_csa_sample` plus Phase 10R UTF-8 staging; `V2.2` is converted only in the derived validation view to Rust-compatible `V3.0`. | Game/source identity, move prefixes, annotations, terminal marker, encoding, raw SHA. | Existing Rust `open-shogi-cli` exporter replays the derived view; source bytes remain unchanged. | 10/10 bounded WCSC32 games accepted. |
| KIF | Denryu sample is CP932 and contains Japanese moves, clocks, `**対局 評価値`, and PV text. | `parse_kif_sample` retains raw Japanese move/eval/PV; `convert_kif_to_csa` uses the printed source square and fails closed on missing/unsupported notation. | Encoding, headers, full move token, raw eval/PV, score perspective `unknown`, raw SHA. | Derived CSA is replayed by Rust; no source KIF is overwritten. | 1/1 bounded Denryu KIF game accepted; 96 moves converted. |
| HCPE | Fixed 38-byte record: 32-byte HCP plus signed score, move, result fields. | Fixed-layout binary adapter. | HCP SHA, raw score, best move, WDL code, unknown semantics/perspective. | Decode HCP, validate kings/hands/move index, replay through local rule engine, round-trip bytes. | Parser unit coverage; no external HCPE artifact acquired. |

| PackedSfenValue / binpack | Existing sample layout is 40 bytes: 32-byte packed position plus score/move/value fields. | Fixed 40-byte adapter; `binpack` is an explicit alias, not a guessed format. | Packed-position SHA, score, best move, raw value, WDL/unknown semantics. | Packed-position decoder, malformed king/hand checks, legal move/index checks, round-trip. | Parser unit coverage; no external nodchip artifact acquired. |
| ZIP | WCSC32 and Denryu hardware-3 archives. | Safe inventory/extraction rejects traversal and symlink members, bounds entries and decompressed bytes, and records archive SHA. | Exact archive name, member names, CRC, compressed/uncompressed sizes, archive SHA. | Inventory before extraction; no overwrite; checksum before activation. | WCSC32: 293 entries / 519,128 uncompressed bytes; Denryu: 135 entries / 12,016,210 uncompressed bytes. |

## Semantic rules

* Unknown score perspective, unit, scale, mate encoding, or teacher lineage is retained as raw metadata and quarantined from training.
* `best_move`, `played_move`, policy visits, WDL, raw evaluation, search depth/nodes/playouts, and PV are separate fields; no field is silently relabeled.
* Exact position/history identities are compared only when the adapter can prove the namespace. Missing identity is reported as unavailable, never as “no overlap.”
* Canonical positions must be produced by the local rule engine or a separately reviewed fixed-position decoder before a source can enter a train/validation/test split.
