# Phase 10R permission-request drafts

These are unsent drafts. They are included so a future maintainer can request precise permission without silently treating public availability as approval. No draft authorizes a download or changes the registry state.

Each request asks for an artifact-by-artifact answer on:

1. raw game/data training;
2. normalized-data and raw-data redistribution;
3. derived model/evaluation-weight publication;
4. commercial use;
5. attribution and required notices;
6. source lineage and derivative datasets;
7. public-test/holdout restrictions; and
8. exact revision, checksum, and acceptable scale.

The recipient, contact channel, and final response must be filled by a human maintainer before sending.
